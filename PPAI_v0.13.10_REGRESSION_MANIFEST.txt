SOLVER CHANGE
solver.html receives a STOP SEARCH — KEEP BEST FOUND button modeled on the PSAI
implementation supplied by the user.

Behavior:
- button enabled only while calculation is running
- manual stop is checked by the same cooperative checkpoints already used for
  PPAI time budgets, including ENDGAME, REACHABILITY, perfect probe, and full search
- a completed/best partial plan already found is retained
- DEEP does not start another pass after Stop is requested
- if stopped before any playable plan exists, the solver says so
- playback itself is not affected

No other solver strategy/heuristic changes were made.
